Graphics and GPU Dependencies
=============================

Validated GPU toolchain
------------------------

- CUDA toolkit 13.3
- NVIDIA GeForce Game Ready Driver 610.74
- NVIDIA PNY GeForce RTX 5070 OC
- Native CUDA target: `sm_120` (compute capability 12.0)

CUDA performs the ray-tracing computation while OpenGL handles presentation and
interactive camera movement. This is the known-working development combination, not
a minimum system requirement.

Required graphics libraries
---------------------------

GLFW

Role: window creation, input, and OpenGL context management.

- Keyboard movement
- Mouse look
- Fullscreen and windowed modes
- Event callbacks
- Frame timing

GLAD

Role: modern OpenGL function loading.

- GPU resource management
- Buffer and texture operations
- Shader and rendering API access

GLM

Role: viewer-side OpenGL camera and transform interoperability where useful.

The shared engine and ray-tracing math must continue using the project's fixed-size
`core/math` types. GLM types must not leak into the shared Scene, CPU renderer, or
CUDA scene records.

Optional development libraries
------------------------------

Dear ImGui

Purpose: runtime debugging and scene control.

- Camera position
- Lighting controls
- Material settings
- Ray bounce count
- Performance metrics
- Render quality

stb_image

Purpose: future texture and HDR environment loading.

- Skyboxes and HDR environments
- Material textures
- Surface maps

OBJ geometry support does not initially require image textures. MTL texture maps are
deferred until the shared texture subsystem is designed.

High-level runtime flow
-----------------------

```text
User input
    |
    v
GLFW and OpenGL viewer
    |
    v
Shared camera/scene state
    |
    v
CUDA ray generation and rendering
    |
    v
CUDA/OpenGL shared display resource
```
